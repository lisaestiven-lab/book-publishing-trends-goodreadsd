# Book Publishing Trends: Goodreads Data Analysis

An exploratory analysis of Goodreads book data: ratings, languages,
publishers, page counts and publishing trends over time.

Prepared by [Miami Book Publishers](https://www.miamibookpublishers.com/),
a publishing company that helps authors publish, design and market their books.

## Files
- `book-publishing-trends-goodreads.ipynb`: the full analysis notebook

## Data
Use any public Goodreads books dataset with a `books.csv` file
(for example, from Kaggle).
